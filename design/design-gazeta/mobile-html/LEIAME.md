# HTML mobile da Gazeta de 1900 (390 px)

Arquivos estáticos, com o CSS dentro de cada página (nenhum arquivo extra). Abra `index.html` no navegador; os links entre as páginas funcionam.

- As fontes (UnifrakturMaguntia, Bodoni Moda SC, Pathway Gothic One, PT Serif Caption) vêm do Google Fonts: precisa de internet na primeira abertura.
- Para ver como no celular, use o modo dispositivo do navegador (390 px) ou abra num telefone.
- `inicio-360.html` e `inicio-430.html` são a mesma Início, para conferir larguras.
- `componentes.html` mostra os componentes e seus estados.
- O menu é um `<details>` nativo, sem JavaScript. As barras superior e inferior ficam fixas ao rolar.
- Textos entre colchetes, como [NOME DO PROJETO], são placeholders. O crédito do modelo 3D (CC BY) ainda precisa ser preenchido.
